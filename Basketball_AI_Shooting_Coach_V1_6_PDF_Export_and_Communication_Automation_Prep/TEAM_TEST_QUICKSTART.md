# Team Test Quickstart

Keep it simple. Use one of these two options.

If you want the fastest path, use:
- TEAM_TEST_ONE_PAGE_CHECKLIST.md
- TEAM_TEST_MESSAGE_TEMPLATE.txt

## Option 1: Fast cloud sharing (best for remote team)
1. Push this folder to GitHub.
2. In Render, create a new Web Service from the repo.
3. Set Root Directory to Basketball_AI_Shooting_Coach_V1_6_PDF_Export_and_Communication_Automation_Prep.
4. Render will use:
   - runtime.txt (Python 3.11)
   - render.yaml (build + start commands)
5. Share the Render URL with your team.

## Option 2: Same-network sharing today
1. On your machine, run run_team_preview_windows.bat.
2. Find your local IP (example 192.168.1.45).
3. Teammates on same Wi-Fi open: http://YOUR_IP:8501

## What to ask the team to test
- Can they open the app and move through key pages?
- Can they run player flow without confusion?
- Can they upload and preview challenge video?
- Can they generate and open PDFs?

## What to ask them to send back
- One thing that broke.
- One thing that felt confusing.
- One thing they liked.

That is enough for the first feedback round.
