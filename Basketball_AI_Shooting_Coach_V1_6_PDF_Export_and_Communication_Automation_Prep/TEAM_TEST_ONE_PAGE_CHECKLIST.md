# Team Test One-Page Checklist

Use this when you want fast, practical feedback.

## Before You Start (Host)
- App is running (Render URL or local network URL).
- Team can open the URL.
- Ask each tester to spend 10-15 minutes.

## What Each Tester Does
1. Open the app.
2. Pick a player and move through key pages.
3. Upload one challenge video and check preview.
4. Run one evaluation flow.
5. Generate one PDF and open it.

## What Each Tester Sends Back
- One thing that broke.
- One thing that felt confusing.
- One thing they liked.
- Screenshot if something failed.

- Ease of use:
- Reliability:
- Speed:
- Would you use it again:

## Release Decision Rule
- Go if no blockers and average rating is 4.0 or higher.
- Hold if any blocker appears or average rating is below 4.0.

## Simple Blocker Definition
Any issue that prevents completing one of these:
- Open app
- Upload/preview video
- Complete evaluation
- Generate/open PDF
